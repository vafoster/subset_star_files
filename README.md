For use in Cryo-EM data processing. A simple script to truncate a .star file to match input of a sample of particles in .mrcs format. Ex. downloaded a subset of .mrcs particles from an EMPIAR entry with a .star file containing information for the full particle set which will error when you try to load the particles in cryosparc. This script will match the particles you have downloaded to their specific coordinates in the .star file and create a new subset.star file. Made so you don't have to use tokens.
